# 旧Hook設定の手動資料

この文書は旧Hook方式の資料です。

現行のインストーラー、アンインストーラー、通常起動はHook設定を読み書きしません。

新規インストールでHookを登録しません。

既存Hookを自動削除しません。

## 現行方式を使う場合

Hook設定を変更せずに、通常のHUDを起動します。

```powershell
CodexHud.exe
```

HUDは`CODEX_HOME\sessions`と任意の`state_5.sqlite`を監視します。

## 旧設定を手動で扱う場合

`tools\install-hooks.ps1`は旧方式の手動資料として残っています。

実行前に`hooks.json`をバックアップしてください。

旧Hookの追加、変更、削除は、利用者が対象イベントとコマンドを確認したうえで明示的に実行してください。

現行HUDの状態同期を成立させるために、旧Hookを追加する必要はありません。

## `--hook`

現行の`CodexHud.exe --hook`は終了コード0で即時終了します。

状態更新、HUD起動、Named Pipe送信をしません。

既存Hookを残しても、現行HUDの表示集合はローカル記録から再構成します。

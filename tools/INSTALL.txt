Codex HUD Windows x64 package

Requirements
- Windows x64
- No .NET Desktop Runtime is required.

Install
1. Extract this ZIP to a local folder.
2. Open PowerShell in the extracted folder.
3. Run:

   powershell -NoProfile -File .\Install-CodexHud.ps1

The installer does not read or change hooks.json.
It does not register a new Hook.
It does not remove an existing Hook.

The installer creates or updates the Start menu shortcut named Codex HUD.
It stores the app under %LOCALAPPDATA%\CodexHud\App.
It keeps position.json under %LOCALAPPDATA%\CodexHud.
The HUD rebuilds its session set from local Codex records at every start.

Uninstall
Run:

   powershell -NoProfile -File .\Uninstall-CodexHud.ps1

The uninstaller does not change Hook settings.
It keeps position.json and unrelated local files.
